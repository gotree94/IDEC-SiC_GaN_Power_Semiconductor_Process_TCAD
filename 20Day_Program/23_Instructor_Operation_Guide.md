## 5. 난이도 조절

### 5.1 배경이 약한 반

- Day 1–3에 **계산 워크숍 30분 추가**.
- Lab은 Excel template 제공.
- TCAD는 GUI 중심, script는 선택.
- 퀴즈 5문항 중 2문항은 개념.

### 5.2 배경이 강한 반

- Day 2부터 Python 1D solver 직접 작성.
- Day 9부터 DOE/자동화.
- Day 13–14 논문 재현 과제.
- 캡스톤 난이도 상향(3.3 kV/10 kV).

### 5.3 혼합 반

- 2인 1조 **멘토-멘티** 구성.
- 실습은 기본/심화 2트랙.
- 발표는 팀별 난이도 차등.

## 7. FAQ

### Q1. TCAD 라이선스가 없다.

- Python 1D/DEVSIM으로 대체.
- 평가는 **물리/계산/해석** 중심.
- 상용 결과는 강사 demo로 보여줌.

### Q2. 수강생이 공정 경험이 없다.

- Day 5–6에서 **8대 공정** 복습.
- 장비 사진/영상으로 보충.
- 실습은 데이터 분석부터.

### Q3. 결석자가 있다.

- 1일: 데일리 파일 + 실습 데이터 자습, 30분 멘토링.
- 2일 이상: 보충 세션 1회.
- 3일 이상: 수료 기준 재검토.

### Q4. 진도가 느리다.

- Case 1h를 30분으로 축소.
- Lab을 1.5h로.
- 퀴즈는 3문항으로.
- **핵심 계산은 생략하지 않는다.**

### Q5. 진도가 빠르다.

- 논문 재현 추가.
- DOE/자동화.
- 캡스톤 중간 발표.

## 8. 안전/윤리

- 화학물질(HF, piranha)은 **교육 시연만**, 직접 취급 금지.
- TCAD/측정 데이터는 **사용 허가** 확인.
- 회사 기밀/개인정보 저장 금지.
- 논문 인용은 DOI/표준번호 확인.
- 확인되지 않은 수치는 "미확인"으로 표시.
